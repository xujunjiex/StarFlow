# 书库存储模块

本文说明漫画与小说共享书库的会话、存储与保存约束；源码和测试为事实来源。

## 目录与身份

根目录固定包含 `manga_import/`、`novel_import/`、`.starflow/library.json`、`.starflow/catalog/`、`.starflow/books/<UUID>/` 和 `.starflow/legacy/`。默认使用原应用专属外部目录，自定义位置由系统 SAF 文件夹选择器授权。提供器空间未知时不替换为内部磁盘容量。

`LibrarySession` 捕获实际位置身份、会话代次、后端与工作数据库。运行中的作品键包含目录身份、类型和 UUID；复制同一便携 UUID 的根目录也使用独立工作数据库。持久化定位使用根内相对名称；document ID 只用于提供器查询，不解释为文件路径。

## 提交与恢复

修改与待写操作在同一 Room 事务保存。目录写入使用不可变载荷与完整提交标记，校验后才确认本地待写项；不依赖 SAF 原子重命名。`LibraryJournal` 只接受完整的单分支提交链，版本冲突停止覆盖。每 100 次提交生成校验过的恢复快照；删除完成后提交完整状态锚点，再清理已删除作品的旧日志。载荷和快照只记录便携作品键。处理记录按显式构造字段顺序解码，不能依赖 JVM/ART 反射字段顺序；修改实体时同步更新编解码 schema 与混淆保留规则。源书不建立内容指纹。工作数据库的损坏回调保留原文件和待写项，禁止自动删库重建。Room schema 后续升级必须显式提供迁移；目录格式不兼容时停止写入。

SAF 待写来源和产物存于内部持久目录；读取租约结束后释放已确认的副本。失败保留本地待写项和旧有效状态，界面显示保存状态；不得向另一个目录补写。文件更新按字段修改，不能用旧实体回滚新书名或进度。封面和超分先写新修订、验证、提交引用，再清理旧文件；清理意图保留到成功，待写队列引用的产物不能当作半成品删除。

## 扫描、任务与切换

来源扫描只能通过导入弹窗启动，进程级任务逐本提交；页面进入、恢复和下拉不自动识别来源。已记录路径保留身份，缺失来源保留书目，不进行内容匹配或外部编辑修复。管理目录、临时文件和 benchmark 输出不是候选。

切换期间停止接收新操作，等待旧任务、扫描、阅读租约及原生处理结束。原目录写回失败仍可切换；返回原位置先尝试补写。通知和阅读器入口同时验证目录身份与 UUID。

## 删除与升级

删除先持久化意图，随后停止任务、拒绝迟到写入、检查根边界与来源重叠，再删除来源和 UUID 产物；全部成功后提交移除条目。失败保留删除占位供重试，扫描不能复活待删除来源。

默认书库从旧 SharedPreferences 和历史数据库迁移；旧文件与数据库不删除；共享旧来源复制为独立副本后，原来源作为旧资料排除扫描。进度重置，旧 OCR、译文及超分归档且失效。损坏记录、不可访问目录和权限错误不能解释为空书库，也不能触发孤儿清理。
