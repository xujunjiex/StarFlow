# 书库存储模块

本文说明漫画、小说的目录身份、内部数据库、作品文件保存与记录导出约束；源码和测试为事实来源。

## 目录与身份

默认使用应用专属外部目录，自定义位置使用系统 SAF 授权。目录保存 `manga_import/`、`novel_import/`、`.starflow/library.json`、`.starflow/storage.json` 和 `.starflow/books/<UUID>/`。作品目录保持原格式；管理目录仅保存身份、来源索引、封面与超分等产物，不持续镜像数据库内容。

身份与管理资料校验正常、根目录可枚举时，缺失的 `manga_import/` 或 `novel_import/` 只重建为空目录，保留已有书目及处理记录，扫描仍将未还原的来源标为缺失。入口同名文件、枚举异常与管理资料缺失不能按空目录处理；不重建旧作品内容，不自动改动现有目录权限。

`LibrarySession` 捕获位置身份、会话代次、实际后端与独立的 App 内部 Room 数据库。位置身份来自规范路径或提供器树身份；目录 UUID 另存于身份文件并与数据库校验。同 UUID 作品在不同位置使用独立数据库及运行时键；目录身份变化时停止沿用旧记录。提供器 document ID 是定位符，不能解释为文件路径。

管理信息缺失、损坏、无法读取及扫描错误均提供恢复弹窗，不按身份异常类型限制覆盖入口；存储目录窗口始终提供覆盖重建。权限失效可直接重新选择目录，覆盖失败继续保留操作入口。空目录首次收录提示是普通通知，不触发重建提示。

确认后使用新的数据库和 SAF 暂存代次，重建管理信息后关闭旧会话，清除该位置上一代内部数据库、私有历史归档和暂存。仅替换 `.starflow` 管理项，异常项改名保留；漫画、小说来源目录及其中的原文件不得删除、覆盖或搬移，其他书库保留。管理项中可读的作品身份保留，必要时从旧书目的最小来源资料重建，避免 UUID 目录变成显示书名；不继承处理和阅读记录。私有初始化意图先落盘，写入或清理中断后可重放；新库不重复迁入旧全局记录。同位置换代也通知书架重新扫描，旧捕获会话不能启动新任务。

## 记录与文件保存

App 内部数据库是书目、阅读进度、翻译、OCR、超分状态及内部定位映射的唯一活动记录源。DAO 修改和页面重排使用 Room 事务，不生成目录提交日志、记录副本或数据库快照。对正常处理记录的保存不需要目录可写。迟到任务仍必须验证作品类型、UUID 和删除状态；数据库损坏不能自动删库重建。

持久待写队列只用于原文件复制、封面、来源索引和图片产物等文件操作。数据库已保存与目录文件尚未保存必须分别显示；不得因某个产物写入失败声称全部记录未保存。新产物验证后才提交内部引用、清理旧修订；导出租约期间不清理旧文件。失败保留内部暂存文件并允许重试，不向其他书库补写。阅读进度和名称修改不得触发目录递归复制。

旧目录记录仅在内部库未初始化时单向恢复；有本机记录时保留本机事务状态。切换到内部存储后，将旧日志、快照和逐书历史记录校验备份到 App 私有归档，再移除目录中的旧记录副本；不再从旧日志重复恢复。默认书库升级时，旧全局数据库与偏好先归档，再按作品身份、漫画页序及小说分段版本将兼容记录和阅读进度写入内部库；已有新记录优先，不能确认对应关系的旧行保留在私有归档。编解码字段顺序用于旧资料读取和显式导出，不依赖 ART 反射顺序。

GitHub Release `v0.11.2` 使用 v17 全局库，漫画身份兼容时间键及旧标题加时间后缀；当时没有小说和逐页超分。迁移先建立当前页表，再按旧图路径映射记录和阅读位置，不能因目录新增压缩包章节而错位。每本书的待激活标记与首次导入事务一起保存，处理行与完成标记一起提交，失败可重试；进度被修改后不再用旧偏好覆盖。待激活期间清除单页或章节记录会取消该书的自动激活，归档仍可导出。早期“仅归档”构建没有记录清除意图，不能把空行或第一页当作未使用；这些没有待激活标记的归档保留，不自动补填。

## 扫描与页面映射

进入或恢复导入页、切换页签、切换书库与下拉刷新均重新扫描当前可见页签，也可手动启动。扫描指示器和进度计数显示在漫画／小说标题栏内，不插入独立状态行。请求按位置和类型合并，漫画与小说枚举串行执行；后端子项枚举结果复用。已有来源、嵌套来源的外层目录及 UUID 副本不重复收录；权限错误不能当作空目录。

File 来源相对路径从同一组规范路径快照的已校验前缀截取，禁止再次规范化后再求相对路径；书架存在性检查失败进入可恢复错误提示，不能抛到主线程。旧扫描产生的文件／直接父目录重复书目，仅在来源索引逐页位置与顺序完全相同、至多一份有处理记录且双方均无使用租约或待写操作时修复；保留有记录的 UUID，无记录时保留原文件条目。冗余书目及索引先归档到保留作品的私有归档，再事务移除冗余行，不执行来源或产物删除；两份都有记录时保留并提示分别导出。

空目录保存为零页漫画或零章小说，首次收录提醒一次；以后内容纳入原 UUID，用户标题保留。元数据按 `BookMetadataReader.VERSION` 补齐缺失简介；单文件有大小上限，坏元数据不阻止正文导入。独立文件旁只读取归属明确的元数据，不能把共享根目录的普通 meta 应用到所有书。

作品根路径存在性与单页可用性分开记录，只有根路径缺失才标记整本丢失。不可变来源索引保存相对路径、容器类型和条目名，作为稳定页键，并在 App 内保留以支持整个来源目录丢失后的查看和导出；缺失页保留占位和处理记录，不检查同名内容替换。新增、删除或恢复页后，在同一内部事务重排翻译／超分行并重置阅读进度；仅读取元数据变化不重置。来源更新等待该作品阅读或处理租约结束，继续扫描其他作品。

缺页仍有处理记录时提示；用户忽略的稳定键随书目保存，后续不重复提醒这些记录。缺页不得从显示缓存取旧图，也不得因读取失败覆盖旧处理行。PDF 分页变化保留旧页表，避免新页号误用旧记录。

## 作品数据与导出

`BookRef` 包含位置身份、类型和 UUID。`BookData` 按此键查询内部数据库的完整快照及分页记录，不能按数字 id 猜归属。导入卡片的信息图标、缺失弹窗和两种阅读器第四个面板均进入共用数据页，不依赖原文件可读；数据页可导出任何作品，缺失卡片另有小图标快捷入口。

数据页默认展示作品概况；身份与来源折叠，正文采用系统原生长按选区，不拦截长按整段复制，不提供单独复制按钮。卡片内连续字段合并为同一可选择文本区，支持跨字段选取；记录摘要同样可选，独立的详情入口避免选区与点击冲突。

处理记录用分类 chips 和摘要行分页展示；详情、原始数据和说明统一使用与阅读器相似的展开底部面板。面板正文为单个可选择文档：翻译／OCR 按原文字块编号配对，保留多行和仅原文或仅译文记录；小说插图载荷按文字块展示。超分按图片与产物、分阶段耗时、请求参数和实际执行参数分组，身份定位放末尾；原始 JSON 在同一面板菜单中切换。格式化仅展示记录，不重新处理原书或改写数据库。刷新、导出、原始数据及存储说明统一放在工具栏菜单；小说不展示漫画专属字段。查询任务持有书库租约，切换分类时取消旧请求。

显式记录包包含书目、全部处理行、来源索引、该作品的历史归档及可获取产物，不包含原书。输出到系统 Download，缺失产物在清单说明，取消或写入失败清理未完成文件。导出不重新渲染译图，不等待目录可写；持有书库和作品租约，避免删除或产物清理破坏结果。当前版本不导入记录包。

仅复制书库目录不能携带内部数据库记录。迁移到其他设备或清除 App 数据前需要显式导出；目录中的身份和索引不能充当记录备份。

## 删除与目录切换

删除意图首先保存在内部数据库，停止任务并拒绝迟到写入，再清理原文件、UUID 产物及对应内部归档；全部完成后移除书目。来源已经不存在时允许清理残留记录。仍存在的来源与其他书目重叠时停止删除，并指出冲突书名、路径和 UUID；共享父目录不得因清空而误删。

App 导入副本清理整个 UUID 目录；手动来源不搬移或改名，仅清理归属明确的来源、元数据和未被其他书目使用的空父目录。清理计划支持中断重试，已移除书目不能因后续文件清理失败重新写回。当前任务显示“删除中”，实际失败或进程中断才显示“删除未完成”。

切换等待旧任务、阅读及原生处理租约结束。位置之间的数据库和待保存文件隔离，失败不会串库。返回默认目录不递归校验模型、日志等无关子目录；SAF 显示提供器可读名称。授权、枚举及文件操作错误统一显示红色可复制提示。

漫画与小说的导入目录创建共用 `utils/FileAccessDiagnostics.ensureDirectory()`，保留系统失败原因，并报告目标、上级目录的读写与遍历权限及 UID/GID。ADB/MTP 创建的目录可能只允许 App 读取，不能因目录存在而判定可写；App 不擅自修改权限、移动或重建来源目录。普通导入错误同样提供红色可复制详情和存储位置入口；覆盖书库记录不能修复文件系统权限。小说批量导入错误完整汇总，弹窗内容跨视图重建保留。

导入前通过 `LibrarySessions.prepareImport()` 检查目标导入根目录，在预留 UUID 和复制来源前验证真实写入及临时文件清理能力；File 和 SAF 共用此入口。不可写不阻止浏览旧书、不清库或自动换库；存储窗口另行显示不可写的 File 导入目录。只读检查与目录管理损坏分开，不自动把导入写权限失败升级为覆盖重建提示。
